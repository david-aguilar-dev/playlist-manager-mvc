# 🎵 Music Playlist Management System (MVC)

A C# application built using the Model-View-Controller (MVC) architectural pattern to decouple user interface handling, business logic, and media playback state management.

## 📌 Project Overview
This project implements clean software architecture concepts to manage audio tracks and customized media playlists. By applying the MVC pattern, it ensures code maintainability, scalability, and clean separation of concerns.

## 🚀 Key Architectural Features
- **Model:** Represents audio entities, media track collections, and playback properties.
- **View:** Provides intuitive interface handlers for track visualization and user interactions.
- **Controller:** Processes user commands, manages track addition/removal, sorting, and state transitions.
- **Advanced OOP:** Extensively uses interfaces, polymorphism, and modular data processing.

## 🛠️ Tech Stack
- **Language:** C#
- **Architecture:** Model-View-Controller (MVC)
- **IDE:** Visual Studio
